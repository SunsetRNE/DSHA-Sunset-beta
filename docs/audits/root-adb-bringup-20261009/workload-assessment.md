## 历史估算的适用范围

原评估给出 A 34–40、B 15–18、C 16–24、D 9–12 人时，总计 74–94 人时；R3 为 96–124 人时。这些是原作者的人时模型，不是设备或本轮实施耗时实测，也不能作为当前剩余工期。原值保留在 ORIGINAL，未改写历史证据。

新增实现消除了原估算中的部分编码工作，但验证范围需要补上授权撤销、主进程与网络 namespace 事实、事务中断恢复、外部配对并发、双栈顺序和 UI 重建。本轮没有动内置 Harness 插件，因此无需将 Web 插件改动强绑为完成条件；原生来源变更仍需更新受管描述符。持续 root 模块与 chroot 另立工作包。

## 不再采用的假设

- daemon UID 0 不能独自证明客户端会话完整同权；容器 UID 0 也不代表 Android root。
- 属性回显不能证明回环绑定；IPv4 成功不能证明 IPv6 已保护。
- 空授权表不能证明从未配对；撤销不能默认清空共享表。
- 外部 root/系统配对写者不一定遵守本实现的锁；提交前复核不是全系统 CAS。
- 超时不能按“未执行”处理；观察、后续清理与重放必须区分。
- 一个 chroot ENOENT 不能证明权限已过或解释器一定缺失；L1 仍待执行与回收证据。
- 主机单测、源代码编译、完整 APK 和设备验收是不同结论。

## 当前验证入口

```bash
python3 -B tools/test-root-support.py
python3 -B tools/test-root-bootstrap-endpoint.py
python3 -B tools/test-native-device-policy.py
python3 -B tools/test-device-shell-policy.py
python3 -B tools/check-ui-i18n.py
python3 -B tools/run-host-tests.py --check-manifest
python3 -B tools/verify-runtime-descriptor-source.py
```

定向 runner 使用 JDK 17 和锁定缓存中的真实 JUnit/Hamcrest/JSON，不伪造 JUnit；可用 `--gradle-user-home` 指定依赖缓存。它通过假 I/O 执行生产事务代码，覆盖跨实例中断恢复、公钥选择性撤销、双栈、授权代次及既有设备策略、su 路径和安装包身份；不执行 Android 特权操作。固定端点脚本另有隔离主机回归。

完整发布门禁仍以 BUILD 为准。API 37.0 SDK 已准备；仓库未提交的离线归档缺失时，代码验证可显式排除资产生成任务，但必须保留命令和限制，不能称完整 APK 构建成功。最终测试数字、编译/Lint 结果、归档 deferred 项和源码摘要集中写入本轮验证说明，避免多个文档维护不同数字。

## 交付与回退

源码交付包含实现、测试、原生 UI、修订文档、精确差异及摘要。原始评估文件逐字节保留，不把旧原型脚本当作执行入口。当前未部署设备动作，因此本轮无需也没有执行设备回滚。

后续设备动作的回退必须依据 root 私有事务和实际状态：关闭本应用拥有的监听、选择性撤销本应用新增公钥、最后清理本应用规则。不能通过还原整个旧授权表或删除未知记录来回退，也不能把源码回退当成设备状态已恢复。
