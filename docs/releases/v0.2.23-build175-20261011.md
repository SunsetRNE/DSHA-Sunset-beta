## 改了什么

**授权模型（ADR 0005 §2）**

- `util/DeviceAuthorization` 增加「ADB 全局授权」语义：四来源（USB 调试 / 无线调试 / Shizuku /
  Root 自举）任一 GRANTED 即 `globalState() == GRANTED`；`globalReason()` 给出「最接近可用」的原因。
- `plan()` 改为：Root 授权（独立权威，不受总开关影响）→ **总开关关则连 Shizuku 也不用** →
  Shizuku → ADB。修掉了"总开关关着、Shizuku 分支却先于它执行"的语义缺口。
- 单测：128 组新语义矩阵 + 「总开关开 ⇒ 与历史通道顺序一致」对照 + 「任一来源激活」四例。

**执行期**

- `HttpShellService.deviceExecute` 不再自己写 if 链，只问 `DeviceAuthorization.plan()`；
  无通道时把决策理由附在既有的 `[DEVICE_CHANNEL_UNAVAILABLE]` 文本后（标记与退出码不变）。
- `core/DeviceAuthorizationReader` 增加 `adbEntrySummary()` / `sourceLine()`，供入口行与四节共用。

**UI（ADR 0005 §3）**

- 首页只剩两个入口：**ADB 全局授权**（入口行带总开关，开=全局授权、关=全局无 ADB 授权）与
  **Root 授权（独立）**。
- 新增 `AdbAuthorizationActivity`：① USB 调试授权（只读检测）② 无线调试授权（配对/验证）
  ③ Shizuku 调试授权（标明中间层来源）④ Root 自举 ADB 授权（原自举卡整体迁入）。
- 新增 `RootAuthorizationActivity`：`允许 Root Shell` 开关 + 验证 + su 状态；页内无任何 ADB 开关。
- 自举卡抽成 `res/layout/card_root_bootstrap.xml`，供 ADB 授权页复用。
