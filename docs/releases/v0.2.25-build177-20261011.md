## 改了什么

**ADB 授权页 = 四个入口**（`ui/AdbAuthorizationActivity` 重写）：

| 入口 | 去向 |
|---|---|
| ① USB 调试授权 | 新增 `UsbAuthorizationActivity`（只读检测 + 打开开发者选项） |
| ② 无线调试授权 | **`AdbPairActivity`**（沿用既有配对/验证页，未重画） |
| ③ Shizuku 调试授权 | 新增 `ShizukuAuthorizationActivity`（状态 + 中间层来源 + 授权/验证 + 打开管理器） |
| ④ Root 自举 ADB 授权 | 新增 `BootstrapAuthorizationActivity`（自举卡整体迁入） |

- 每个入口行只显示一行状态（已取得 / 状态（原因）），由同一份授权快照每 1s 重算，不再把
  动态明细铺在索引页上。
- `CardPage` 增加 `entryRow(...)`（返回状态行 TextView），`entry(...)` 复用同一实现。
- 自举卡内文案「请先开启**上方**『允许 Root Shell』」改为「请先在**『Root 授权』页**开启…」，
  因为 root 开关已不在同一页。
- Root 授权页在没有 root 时给出去 Root 授权页的入口。
