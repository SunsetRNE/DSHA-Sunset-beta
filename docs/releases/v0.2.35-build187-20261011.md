# v0.2.35 / build187（2026-10-11）环境维护在冷热启动都可见 + 维护文档

## 背景

用户连续两次反馈："覆盖安装后我这边看不到环境维护页，而你（虚拟屏）拉起来就有"。
查证结论：**不是环境状态不同，是启动方式不同**。

- 跳维护页的门禁只在 `MainActivity.onCreate` 里判断一次；
- `vscreen/launch` 是**新建 Activity**（冷启动）→ 走门禁 → 进维护页；
- 用户点图标是把**已在运行的任务**拉到前台（热启动）→ 不重跑门禁 → 看不到；
- 而且"我刚把界面留在虚拟屏里"这件事本身就会让用户的打开变成热启动（非预期干扰）。

## 改了什么（零 `runtimeId`）

`ui/MainActivity` 的横幅（`refreshRecovery`）原本只覆盖两种情况：

- 维护**正在跑**（`BackupTask.maintenanceBusy()`）→「环境维护进行中 · 点击查看进度」；
- 受限模式（`EnvironmentUiStatus.recovery`）。

build183 补了"存在未完成事务"（`MaintenanceCoordinator.pending`）；
**build187 再补"运行身份不是最新"**（`EnvironmentAccess.requiresMaintenanceBeforeStart`，
即 §2 条件 ③），文案统一为「**环境维护待处理 · 点击处理**」。
两者都在 `onResume` 探一次（异常降级为 false），因此**热启动也能看见并点进维护页**。
